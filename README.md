# ASSIGNMENT-5
## Task 1: Dictionary of Student Marks
In this task, a Python program is created to store student names and their corresponding marks using a dictionary.
### Functionality:
- A dictionary is created with student names as keys and marks as values.
- The user is asked to enter a student name.
- If the student exists in the dictionary, their marks are displayed.
- If the student does not exist, an appropriate message is shown.
## Task 2: List Slicing
In this task, list slicing operations are demonstrated using a list of numbers.
### Functionality:
- A list of numbers from 1 to 10 is created.
- The first five elements are extracted using slicing.
- The extracted list is reversed.
- Both the extracted list and the reversed list are displayed.
## Conclusion
This assignment demonstrates basic Python concepts such as:
- Dictionaries
- Lists
- User input
- Conditional statements
- List slicing
